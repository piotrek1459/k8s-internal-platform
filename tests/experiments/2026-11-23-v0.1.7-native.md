results do not establish cross-version upgrades or backup restoration. v0.1.6 was

## Final state and evidence

One healthy owned lifecycle demo remains. Final inventory verified zero
configuration Secret metadata, registry credentials, configuration Kubernetes
values and application volumes, with one application Deployment/Pod. Diagnostic,
Secret and public-image fixtures were removed. Dedicated persistence/cleanup
sessions were revoked and their saved cookies removed. Root Kubernetes proxies,
management forwards and SSH control connections were stopped.

Generated administrator credentials remain in the ignored mode-0600
`native-v017/access.json` file under a mode-0700 directory. Raw results are private;
the [machine-readable summary](2026-11-23-v0.1.7-native.json) records check
descriptions, source/image identity and evidence hashes without credentials.
Disk observation was 29 GB total, 7.9 GB used and 20 GB available. This is a
capacity observation, not calibrated resource presets or a performance dataset.

## Repeatability and remaining work

`tests/e2e/native.py --secret-cleanup-phase hold|resume` makes the published Secret
workflow repeatable. An operator replaces the broker and reconnects the loopback
forward between phases; resume requires a changed container identity with the
same PVC and original saved session. The fixture repair refuses changed
UID/namespace/ownership/version and uses UID/resource-version patch tests.
Its guard regressions bring the Python suite to 73 passing cases.

The native installation/Secret-cleanup gate in issue #16 is complete for v0.1.7.
Private LAN HTTPS/DNS/trust and actual second-device routing remain outstanding;
SSH/loopback forwarding does not establish that acceptance. Remaining worker
crash/restoration barriers, comprehensive negative-path disclosure, resource
calibration and controlled repeated evaluation remain core work. Application
volumes/verified backup restoration (M5), public internet hosting (M6) and supported
cross-version upgrades (M7) retain their separate requirements.
